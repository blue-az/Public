Exact task prompt

In this small Python package, implement support for the standard Retry-After response header.

1. Implement retry_delay in src/retry_policy.py according to its docstring: exponential fallback 1 * 2**max(0, attempt) capped at 30 seconds; accept signed integer seconds or an HTTP date; treat naive datetimes as UTC; use current UTC when now is omitted; use the fallback for invalid headers; clamp the final delay to [0, 30].
2. Update delay_for_response in src/client.py to pass the response's Retry-After header and forward now.
3. Update docs/retries.md to document the behavior.
4. Run python3 tests/check_retry_after.py from the starter root. It must exit 0 and print RETRY_AFTER_OK.

Only change src/retry_policy.py, src/client.py, and docs/retries.md. Do not change the supplied test.

Starter files

src/retry_policy.py

from datetime import datetime

BASE_SECONDS = 1
MAX_SECONDS = 30


def retry_delay(attempt, retry_after=None, now=None):
    """Return retry delay in seconds.

    Exponential fallback is 1 * 2**max(0, attempt), capped at 30 seconds.
    Retry-After may be a signed integer number of seconds or an HTTP date.
    For a date, compare against `now`; naive datetimes mean UTC. If `now` is
    None, use current UTC time. Invalid headers use the exponential fallback.
    Clamp every final delay to [0, 30].
    """
    raise NotImplementedError

src/client.py

from src.retry_policy import retry_delay


def delay_for_response(attempt, response, now=None):

import sys

from email.utils import format_datetime

NOW = datetime(2026, 2, 3, 12, 0, 0, tzinfo=timezone.utc)

assert retry_delay(0, now=NOW) == 1
assert retry_delay(1, now=NOW) == 2
assert retry_delay(8, now=NOW) == 30
assert retry_delay(2, "7", now=NOW) == 7
assert retry_delay(2, "-4", now=NOW) == 0
assert retry_delay(2, "31", now=NOW) == 30
assert retry_delay(2, "not a date", now=NOW) == 4
assert retry_delay(2, format_datetime(NOW + timedelta(seconds=9), usegmt=True), now=NOW) == 9
assert retry_delay(2, format_datetime(NOW - timedelta(seconds=9), usegmt=True), now=NOW) == 0
