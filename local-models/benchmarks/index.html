Why this page exists

A benchmark result without its protocol cannot be checked, and a protocol restated in prose drifts away from the runs it describes. Every definition here is generated from the file the harness and the internal dashboard both read, so there is one source rather than three descriptions that agree until they do not.

The E9 standard is two legs, not one

The quality leg and the wall-clock leg run over different task sets, in separate runs, to separate evidence roots. They share exactly one task. A quality count therefore does not vouch for a time recorded beside it, and warm means include failed trials unless a row says otherwise.

A cell has three outcomes

Pass and fail are not enough, because a harness fault and a wrong answer look identical in a pass count. Both produce a number rather than an error.

  • pass — graded correct, with every proof below satisfied
  • fail — graded incorrect AND every proof below satisfied. Only this counts as evidence about the model.
  • unproven — any proof missing or failed. Not a model result, not poolable, and never rendered as a score. Recorded with its raw trace for forensics.

A failing cell is promoted to fail only when all five proofs hold:

ProofWhat it establishes
dispatchthe call happened — non-zero tokens, a resolved model identity, no no-dispatch state
scopethe graded fixture is byte-identical apart from the model's own intended edits
placementthe model ran where the row says it ran, from the host's own telemetry
graderthe failure survives a grader spot-check. A deterministic grader that has never been boundary-tested against negation, synonyms and section headings is a suspect, not an oracle.
timingthe trial completed without timeout, and the recorded time excludes harness bookkeeping

Default to unproven. Promoting unproven to fail requires the proofs, not an argument that the model probably was wrong. Mixed results across a roster are the signature of an unproven cell class, so triage the instrument before interpreting the spread.

Bridge run. The cheap way to settle a suspected-material change: re-run one cell class on both versions on ONE host, small n, and compare. A bridge run answers the question for the whole corpus. Absent one, do not assume a version delta explains a result — and do not assume it does not.

What may never be pooled

Pooling is forbidden by default: results may only be compared within one definition, on one host.

  • e9-standard-l2 &mdash; e9-extension-l1 &mdash; e9-extension-l0
  • z13-max390 &mdash; testbench-native
  • testbench-native &mdash; testbench-hybrid
  • e9 local rows &mdash; Haiku staged control
  • fusion-l3-retained &mdash; fusion-l3-v2
  • blind-read rounds with each other &mdash; since each is one observation
  • different model digests or tags

Counts accumulate over different corpora with different denominators. A rate computed across them is arithmetic, not a measurement. Quality rank transfers between chips; speed rank does not. The Z13 penalty against the 3090 varies by task and reverses, so no single multiplier exists.
