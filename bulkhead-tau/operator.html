Operator records tasks, claims, evidence, and verification so an agent’s report of completion can be checked against recorded evidence.

A separate control plane

Operator is a standalone, domain-neutral project for tracking agent work and the evidence behind completion claims. It is designed to distinguish a claim from the evidence and verification recorded against it; recording a verification does not by itself guarantee correctness.

Bulkhead τ may use Operator, but Operator does not depend on Bulkhead τ. Operator is not part of Bulkhead τ’s engine room, is not bundled with Bulkhead τ, and is not required to use it.

In Operator’s default single-user mode, verification is advisory: the same OS user can enter a reviewer’s name. An identity-isolated verification requires enforced identity configuration and a verifier running under a distinct registered OS identity. Do not treat advisory verification as an independent check.
